# 이마트 POS 영업 대시보드

이마트 POS 「기간별매출(상품별)_일별상세」 엑셀로 만드는 영업 대시보드입니다.
**엑셀만 `data/raw/` 에 올리면** GitHub가 자동으로 데이터를 변환하고 대시보드를 다시 배포합니다.

탭 구성: 1. 매출 종합 · 2. 변동 원인(워터폴·드릴다운) · 3. 품목별 실적 · 4. 점포별 실적 · 5. 예측 시뮬레이션

> 매출(판매금액, 이마트 매입원가 기준)과 판매수량을 함께 보여 줍니다. 같은 양식의 **수량 파일**과 **금액 파일**을 매달 하나씩 올리면 됩니다.
> 금액 파일이 없는 달은 수량만 표시되고 매출은 비어 있습니다.

---

## 폴더 구조

```
├─ index.html                     ← 대시보드 화면(로직). 데이터는 들어 있지 않음
├─ data/
│  ├─ raw/                        ← 여기에 월별 POS 엑셀을 올립니다
│  │   ├─ emart_pos_202501.xlsx          (수량)
│  │   ├─ emart_pos_amount_202501.xlsx   (금액)
│  │   └─ …
│  └─ pos_data.json               ← 자동 생성(직접 수정하지 마세요)
├─ scripts/build_data.py          ← 엑셀 → pos_data.json 변환
└─ .github/workflows/update-dashboard.yml   ← 자동 변환·배포
```

## 처음 한 번만: 저장소 만들기

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다(기본 브랜치 `main`).
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. **Actions** 탭에서 「대시보드 데이터 갱신·배포」를 열고 **Run workflow** 를 한 번 눌러 줍니다.
4. 1~2분 뒤 Settings → Pages 에 나오는 주소(예: `https://<계정>.github.io/<저장소>/`)로 접속합니다.

> **보안 주의:** 공개(Public) 저장소의 Pages 주소는 누구나 볼 수 있습니다. 판매 데이터이므로 **비공개(Private) 저장소**를 권장합니다.
> 비공개 저장소에서 Pages 를 쓰려면 GitHub 유료 플랜(Pro/Team/Enterprise)이 필요하고, 사내 사람만 보게 하려면 Enterprise 의 비공개 Pages 설정이 필요합니다.
> Pages 를 쓸 수 없으면 아래 「서버 없이 보기」 방법으로 쓰면 됩니다.

## 매달 할 일: 엑셀만 올리기

1. 이마트 파트너 시스템에서 해당 월 「기간별매출(상품별)_일별상세」 엑셀을 **수량**과 **금액** 두 가지로 내려받습니다.
2. 파일명에 **연월 6자리(YYYYMM)** 가 들어가게 합니다.
   - 수량 파일 예: `emart_pos_202601.xlsx` 또는 `emart_pos_수량_202601.xlsx`
   - 금액 파일 예: `emart_pos_amount_202601.xlsx` 또는 `emart_pos_금액_202601.xlsx`
   - 이마트에서 받은 이름 그대로(`기간별매출(상품별)_일별상세_202601(수량).xlsx`, `…(금액).xlsx`) 올려도 됩니다.
   - 수량/금액은 **값 크기**로 판별합니다(일별 값의 중앙값이 100 이상이면 금액). 파일명의 `수량`·`금액`·`매출` 표시와 값 크기가 다르면 Actions 로그에 [주의]를 남기고 값 크기를 따릅니다.
3. GitHub 저장소 → `data/raw` 폴더 → **Add file → Upload files** 로 올리고 **Commit changes**.
4. 1~2분 뒤 대시보드 주소를 새로고침하면 반영됩니다. (진행 상황은 **Actions** 탭에서 확인)

- 같은 달 파일을 고쳐서 다시 올리면 같은 이름으로 덮어쓰면 됩니다. 같은 연월·같은 종류 파일이 둘이면 이름순으로 마지막 파일을 씁니다.
- 지난달 금액 파일만 나중에 올려도 됩니다. 그 달 매출이 채워집니다.
- 화면 상단의 **차트·비중 기준(매출/수량)** 으로 차트, 비중, 워터폴, 예측의 기준을 바꿉니다. 표와 요약 카드에는 매출·수량·평균 단가가 항상 함께 나옵니다.
- 여러 해 데이터가 쌓이면 전년 동기 대비, 연간·분기 비교가 자동으로 생깁니다. 예측은 항상 **마지막 12개월**을 기준으로 다음 12개월을 계산합니다.
- 점포 Tier 는 업태별 **최근 12개월** 판매수량 순위(A 상위 20%, B 다음 30%, C 나머지)라 데이터가 쌓이면 자동으로 다시 나뉩니다.

## 서버 없이 보기 (Pages 를 쓰지 않을 때)

`index.html` 을 더블클릭해 브라우저(크롬·엣지 권장)로 열면 「데이터 파일을 불러와 주세요」 화면이 나옵니다.
- 월별 엑셀(수량·금액 파일 모두) 여러 개를 한꺼번에 끌어다 놓거나 선택하면 바로 대시보드가 그려집니다.
- 또는 저장소의 `data/pos_data.json` 하나만 끌어다 놓아도 됩니다(더 빠름).
- 파일은 브라우저 안에서만 읽고 어디에도 전송하지 않습니다. 차트 라이브러리(d3)만 인터넷에서 불러옵니다.

## 내 PC에서 직접 변환하기 (선택)

```bash
pip install openpyxl
python scripts/build_data.py
```

## 바꾸고 싶을 때

| 바꿀 것 | 위치 |
|---|---|
| 품목군 분류 규칙 | `scripts/build_data.py` 의 `group_of()` **와** `index.html` 의 `groupOf()` (두 곳을 같이) |
| 업태 표시 순서 | `build_data.py` 의 `CH_ORDER`, `index.html` 의 `CH_ORDER` |
| Tier 기준(20%/30%) | `index.html` 의 `prepare()` |
| 수량/금액 파일 판별 키워드 | `build_data.py` 의 `AMT_WORDS`·`QTY_WORDS`, `index.html` 의 `kindOf()` |
| 색상 | `index.html` 상단 `:root` 의 `--c0` ~ `--c6` |
